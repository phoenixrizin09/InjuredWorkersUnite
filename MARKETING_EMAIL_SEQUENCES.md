---

## Metrics to Track

Watch these in Brevo dashboard:

- **Open rate** (target: 30-50% for disability audience)
- **Click rate** (target: 5-10%)
- **Unsubscribe rate** (watch for > 2% = subject line issue)
- **Best times** (optimize send time based on opens)

---

## Optimization Rules

**If open rate < 20%:**
- Change subject line (test 2 versions)
- Shorten content (3 paragraphs max)
- Add emoji (disability audience responds well)

**If click rate < 3%:**
- Make CTA clearer
- Reduce competing links (1-2 max per email)
- Change button text (test "Show me" vs "Get this")

**If unsubscribes spike:**
- Review email that caused it
- Adjust frequency if needed
- Add "prefer less email" option

---

## A/B Testing

Pick ONE variable per test:

**Subject Line Test:**
- Version A: "Your Eye Oracle Daily Brief is Ready"
- Version B: "What the agents found while you slept"
- Send to 50% each, winner goes to everyone

**CTA Button Test:**
- Version A: "Show me the evidence"
- Version B: "Get my appeal kit"
- Track which converts more

**Send Time Test:**
- 8am vs 2pm
- Track open rates
- Use winner going forward
