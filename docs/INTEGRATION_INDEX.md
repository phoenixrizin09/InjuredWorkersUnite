## 🎯 Quick Reference

### Essential Commands

**Start Daemon:**
```bash
node daemon/eye-oracle-daemon.js
```

**Start API:**
```bash
node api/core.js
```

**Run All Tests:**
```bash
npm test __tests__/integration*.test.js
```

**Test Endpoints:**
```bash
# macOS/Linux
bash test-integration.sh

# Windows
powershell -ExecutionPolicy Bypass -File test-integration.ps1
```

**Verify Integration:**
```bash
node verify-integration.js
```

### API Endpoints Reference

**Agent System:**
- `GET /api/agents/status` - Get all agents
- `GET /api/agents/:name/logs` - Agent logs
- `POST /api/agents/:name/task` - Send task

**Alert System:**
- `POST /api/alerts/orchestrated` - Process alert
- `GET /api/alerts/orchestrator/status` - Status

**Transparency:**
- `GET /api/transparency/dashboard` - Public dashboard
- `GET /api/transparency/corrections` - Corrections log
- `GET /api/transparency/methodology` - Methodology
- `GET /api/transparency/ai-usage` - AI disclosure
- `GET /api/transparency/conflicts` - Conflicts
- `GET /api/transparency/community-protection` - Protection policy
